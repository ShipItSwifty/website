Welcome to the **ShipItSwifty** documentation.

ShipItSwifty is a Swift-native CLI for iOS and Android release automation. These docs cover everything from installing the binary to writing custom plugins.

## Where to start

- New here? Begin with the [Installation](/docs/getting-started/installation) guide.
- Shipping iOS? See the [iOS Quickstart](/docs/getting-started/ios-quickstart).
- Shipping Android? See the [Android Quickstart](/docs/getting-started/android-quickstart).
- Using Flutter, React Native, or Kotlin Multiplatform? See the [KMP Quickstart](/docs/getting-started/kmp-quickstart).
- Coming from fastlane? Read the [migration guide](/docs/getting-started/migrating-from-fastlane).
- Setting up CI? See the [CI Setup guide](/docs/guides/ci-setup).
- Using a coding agent in the upstream repo? Start with the [Agent Fast Start](/docs/guides/agent-fast-start) guide.
- Need the Swift API? Browse the [API Reference](/docs/api/shipitkit).

## Versioning

The docs in this site are maintained alongside the website. The Swift API reference is generated from DocC and rendered directly at `/docs/api/shipitkit` when synced data is available.
